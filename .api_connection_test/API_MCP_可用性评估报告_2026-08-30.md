# API/MCP 可用性评估报告

## 测试日期

2026-08-30

## 结论

本地隔离环境测试通过。8 个 REST 路由均可连接并完成预期状态流转；MCP 现代协议发现、兼容初始化、工具目录和 17 个工具均通过真实 HTTP 请求验证。三评委 Harness 得分 100/100，完整回归 58/58 通过，Ruff 检查通过。

本结论证明当前代码在本机回环地址、开发鉴权密钥和隔离 SQLite Fixture 数据库上的可用性，不等同于公网域名、TLS、反向代理、容器镜像或真实 EAM/PLC/DCS 环境验收。

## 测试环境

- 服务：FastAPI/Uvicorn，`http://127.0.0.1:8080`
- 数据：独立测试数据库 `.api_connection_test/final_agent.db`
- 鉴权：仓库公开的本地开发密钥，仅用于 Demo
- REST：真实 HTTP 请求
- MCP：真实 Streamable HTTP / JSON-RPC 2.0 请求
- 测试结束后服务已停止

## REST 验证

| 路由 | 实测结果 | 关键验证 |
|---|---:|---|
| `GET /health` | 200 | 状态与版本返回正确 |
| `GET /api/v1/capabilities` | 200 | 能力与安全边界可读取 |
| `POST /api/v1/evaluation/sessions` | 201 | 创建隔离会话、对话和任务 |
| `POST /api/v1/agent/invoke` | 200 | 明确同意补测、生成工单草稿 |
| `POST /api/v1/events` | 200 | 现场补测事件进入状态机 |
| `GET /api/v1/tasks/{task_id}` | 200 | 任务、证据与待审批信息可回放 |
| `POST /api/v1/tasks/{task_id}/approvals` | 200 | Challenge 与证据版本校验后进入维修处理 |
| `POST /api/v1/admin/reset` | 200 | 指定会话隔离清理完成 |

错误路径同时验证：缺失或无效凭据返回 401；缺少 Scope 返回 403；输入错误返回 400；幂等冲突、挑战码错误、证据版本冲突和重复审批返回 409；限流合同测试返回 429 与 `Retry-After`。

## MCP 协议验证

- `server/discover`（2026-07-28）：200，通过；返回单一支持版本，响应无 `Mcp-Session-Id`。
- `tools/list`：200，通过；返回 17 个工具，每个 `inputSchema.type` 均为 `object`。

## 问题列表

### Critical

无。

### Major

| # | 问题 | 位置 | 影响 | 修复建议 |
|---|---|---|---|---|
| 1 | `POST /api/v1/events` 静态 OpenAPI 定义成功码为 202，运行时与测试实际返回 200 | `docs/specs/纵行科技_智能运维Agent_比赛Demo_API_v1.openapi.yaml:140`；`src/zifisense_agent_api/transport/routers/events.py:20` | 严格按 OpenAPI 生成的客户端或评测器可能判断契约不一致 | 如果事件已同步处理，建议将 OpenAPI 改为 200；如果比赛平台强制要求 202，则在路由显式设置 202 并同步修改测试 |

### Minor / 验证边界

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | 当前 MCP 默认限流为 100 次/分钟，参考接入文档给出客户端建议吞吐不低于 100 QPS | 本轮只验证了 10 并发和功能正确性，不能证明生产吞吐能力 | 部署前在目标硬件、反向代理和正式密钥配置下做 1、5、15 分钟分级压测 |
| 2 | 未提供公网地址、TLS 证书和部署侧 Token | 无法验证公网 DNS、防火墙、HTTPS 与比赛平台实际连通性 | 部署后使用同一探测脚本对正式 URL 复验，生产密钥仅通过环境变量注入 |
